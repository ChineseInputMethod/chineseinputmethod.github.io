Windows 8.1<br>
Windows 10<br>
Windows 11<br>
可以[直接下载][download]三拼输入法

下载后，运行安装程序，如果弹出Microsoft Defender SmartScreen 安全拦截提示

![defender](/assets/images/download/windows/defender.png)

点击更多信息

![smartscreen](/assets/images/download/windows/smartscreen.png)

点击仍要运行

![install](/assets/images/download/windows/install.png)

选择默认选项，直到安装完成

![setup](/assets/images/download/windows/setup.png)

点击系统托盘中的语言栏图标，在弹出菜单中选择小狼豪

![tray](/assets/images/download/windows/tray.png)

现在就可以使用三拼输入法打字了

![hello](/assets/images/download/windows/hello.png)
